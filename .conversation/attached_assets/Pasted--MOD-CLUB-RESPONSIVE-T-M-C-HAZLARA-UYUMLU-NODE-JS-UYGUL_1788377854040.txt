# MOD CLUB — RESPONSIVE / TÜM CİHAZLARA UYUMLU NODE.JS UYGULAMA

MOD CLUB uygulamasını Node.js ile geliştir.

Uygulama **Replit'e bağımlı olmayacak**. Daha sonra Windows, Linux, VPS veya normal hosting sunucusunda bağımsız şekilde çalışabilecek.

Temel kullanım:

**Dosyaları yükle → npm install → npm start → Kurulum Sihirbazı → Kullan**

# MOBILE-FIRST

Tasarımı önce mobil ekran için oluştur.

Daha sonra ekran genişledikçe layout otomatik olarak genişlesin.

Telefon:

* Tek sütun
* Büyük dokunmatik alanlar
* Kolay okunabilir yazılar
* Sabit alt navigation
* Floating sohbet butonu

Tablet:

* Daha geniş içerik
* Gerektiğinde 2 sütun
* Kartlar dengeli şekilde büyüsün

Laptop / masaüstü:

* İçerik maksimum genişlikte sınırlandırılsın
* Ekranın tamamına yayılıp aşırı geniş kartlar oluşturulmasın
* Örneğin `max-width` kullan
* İçerik ortalansın

# RESPONSIVE CSS

Sabit piksel değerlerine aşırı bağımlı olma.

Mümkün olduğunca:

* `%`
* `rem`
* `em`
* `vw`
* `vh`
* `clamp()`
* `min()`
* `max()`
* CSS Grid
* Flexbox

kullan.

Font boyutlarında gerektiğinde:

```css
font-size: clamp(...);
```

kullan.

Padding ve boşlukları da gerektiğinde responsive yap.

# BANNER RESPONSIVE

Ana banner bütün ekranlarda düzgün görünmeli.

Mobilde:

* Banner ekran genişliğine göre küçülsün
* Yazılar okunabilir kalsın
* Karakter/görsel kesilmesin
* Buton taşmasın
* Slider okları içeride kalsın

Tablet ve masaüstünde:

* Banner genişlesin
* Görsel kalitesi korunsun
* İçerik aşırı büyümesin

Banner için uygun `aspect-ratio` kullan.

# HIZLI ERİŞİM RESPONSIVE

SOHBET / DUYURULAR / OYUNLAR / TOPLULUK / AFİŞLER alanı:

Mobilde ekranı sıkıştırma.

Küçük telefonlarda:

* Gerekirse yatay scrollable yapı kullan
* Kartlar okunabilir boyutta kalsın

Normal telefonlarda:

* Dengeli şekilde göster

Tablet ve masaüstünde:

* 5 bölüm tek satırda düzgün hizalanabilir

Ancak hiçbir cihazda içerik taşmasın.

---

# DUYURULAR RESPONSIVE

Mobil:

Tek sütun.

Tablet:

2 sütun olabilir.

Masaüstü:

3 sütun olabilir.

CSS Grid kullan.

Örnek mantık:

```css
grid-template-columns: repeat(auto-fit, minmax(280px, 1fr));
```

Ancak 320px gibi çok küçük ekranlarda kartların minimum genişliğini ekranı taşırmayacak şekilde ayarla.

# ALT NAVIGATION RESPONSIVE

Alt navigation tüm cihazlarda düzgün çalışmalı.

Mobil:

```text
ANA SAYFA | SOHBET | ⚡ | OYUNLAR | PROFİL
```

Telefon ekranına tam oturmalı.

Küçük 320px ekranlarda bile:

* İkonlar kesilmemeli
* Yazılar üst üste binmemeli
* Butonlar ekran dışına çıkmamalı

Tablet ve masaüstünde de kullanılabilir ancak gerektiğinde daha kompakt hale gelmeli.

iPhone Safe Area desteği ekle:

```css
padding-bottom: env(safe-area-inset-bottom);
```

---

# FLOATING SOHBET BUTONU

Sağ alt tarafta sabit sohbet balonu olacak.

Ancak farklı cihazlarda navigation ile çakışmamalı.

Örnek:

```css
position: fixed;
right: clamp(12px, 3vw, 24px);
bottom: calc(
    var(--navbar-height) +
    env(safe-area-inset-bottom) +
    16px
);
```

Ekran küçüldüğünde otomatik küçülebilecek şekilde tasarla.

# OVERFLOW KONTROLÜ

Sayfada gereksiz yatay scroll kesinlikle oluşmamalı.

Özellikle:

```css
html,
body {
    overflow-x: hidden;
    max-width: 100%;
}
```

kullanılabilir ancak bu özellik layout hatalarını gizlemek için kullanılmamalı.

Asıl sorun responsive CSS ile çözülmeli.
